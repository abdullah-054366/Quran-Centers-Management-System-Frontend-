# مِشكاة — واجهة إدارة المراكز والحلقات القرآنية

واجهة عربية RTL مبنية باستخدام React وVite وTailwind CSS.

## التشغيل

يتطلب Node.js 20.19+ أو 22.12+.ls

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## محتويات الواجهة

- لوحات حسب دور مسؤول المنصة، مسؤول المركز، المعلم، والطالب مع مبدّل أدوار للمعاينة.
- المراكز والحلقات والطلاب، وتسجيل الحفظ والمراجعة والحضور، وخطط الحفظ، وسجل التعديلات.
- تفعيل/إيقاف المركز، وخيار السماح للطالب بتعديل الحفظ والمراجعة.
- واجهة متجاوبة ومهيأة للعربية واتجاه RTL.

## ربط الباك اند

البيانات الحالية تجريبية وموجودة محلياً داخل `src/App.jsx` لتجربة الواجهة. اربطها لاحقاً بخدمات API عبر طبقة خدمات مستقلة، واحذف مبدّل الأدوار التجريبي. يجب أن يفرض الباك اند عزل `CenterId` والصلاحيات وحالة المركز وتسجيل سجل التعديلات؛ عناصر الواجهة وحدها لا توفر حماية أمنية.
